# 创意 Web 客户端

## 产品定位
把想法、自然现象和科学规律变成可交互的作品。游戏是可选形式，默认不要求分数、胜负或关卡。保留 GameVallies 品牌及浅色背景、深绿色操作、青柠色强调的设计。

## 本次实现
- 桌面首页：创意输入、物理/生物/化学/艺术灵感入口、交互形式确认。
- 我的作品：真实接口列表、分页、状态筛选、当前已加载作品搜索；空状态不填充示例作品。
- 三栏创作台：复用现有创建会话、生成任务、恢复/取消与迭代流程，默认横向呈现。
- 预览：用户主动启动，使用带鉴权的现有 play 接口；生成 HTML 在仅允许脚本的隔离 iframe 中执行。
- 发布：调用真实发布接口，区分公开成功、待审核和请求失败；已公开作品直接展示分享地址。
- 创意描述在登录跳转间临时保存，30 分钟过期且只消费一次。

## 兼容性与边界
保留现有 /games API、数据实体及内部 H5 构建名称，不需要数据库迁移。这里的 H5 是现有 Taro Web 编译目标，不代表新增移动端产品。
账户、订阅和作品详情沿用现有页面，相关文案调整为作品；本次重构集中在桌面首页、作品列表与创作台。
仅展示真实当前版本。现有后端没有版本列表/回滚接口，不提供虚假的历史恢复功能。
科学主题会要求模型、单位、参数范围和简化假设；这不是科学计算正确性的验证机制。领域校验和更深层生成引擎改造需后续后端工作。
